# 대시보드 수주 등록 및 표 사용성 개선 설계

## 목표

수주 공수 대시보드에서 미등록 Tracking No.를 즉시 수주 마스터에 등록할 수 있게 하고, 요약·상세 표를 선택·복사 가능하게 하며, 상세 행 번호와 작업일 정렬을 사용자 관점에 맞춘다.

## 동작

- 요약 행의 차단 사유에 `WORK_ORDER_UNREGISTERED`가 있으면 `검증 상태` 셀에 `수주 등록 이동` 버튼을 표시한다.
- 버튼은 메인 창이 제공하는 콜백을 호출한다. 메인 창은 기존 설정 창을 `수주 마스터` 탭으로 열고 신규 행을 추가한다.
- 신규 행에는 선택한 요약에서 확인되는 Tracking No., 장비명, 업체명, 사업팀을 채운다. 업체명은 기존 활성 업체와 일치할 때만 업체 콤보를 선택하고, 불일치·누락·충돌 값은 비워 사용자가 입력한다.
- 저장 성공 시 기존 수주 매핑 재적용과 원본 목록 갱신을 수행한 뒤 대시보드 요약·상세와 내장 최종 미리보기를 즉시 갱신한다. 취소하거나 저장 실패하면 대시보드는 변경하지 않는다.
- 요약·상세 표는 셀 단위 다중 선택을 허용하고 `Ctrl+C` 및 우클릭 `복사`로 선택 영역을 TSV 형식으로 클립보드에 쓴다. 행 선택 변경에 따른 상세 로드는 현재 행을 기준으로 유지한다.
- 상세 표 첫 열은 DB `row_id`가 아니라 현재 표시 순서의 1부터 시작하는 `행 번호`를 표시한다. 내부 감사·스냅샷용 원본 행 ID는 변경하지 않는다.
- 요약 표는 기본적으로 `최근 작업일` 내림차순이다. 날짜가 없는 항목은 양쪽 정렬에서 마지막에 두며, 동일 날짜는 Tracking No. 오름차순으로 고정한다. `시작일 저장` 옆에 `작업일 오름차`, `작업일 내림차` 버튼을 둔다.

## 경계와 오류 처리

- UI는 설정 및 대시보드 application 서비스를 통해서만 데이터를 갱신한다.
- 수주번호, 장비명은 편집 가능한 자동 입력값이다. 업체는 기존 업체 탭의 활성 업체만 자동 선택하며, 새 업체가 필요하면 사용자가 업체 탭에서 추가한다.
- 기존 수주 마스터의 원자적 저장, 필수값, 중복 수주번호 검증을 그대로 사용한다.
- 수주 등록 콜백이 없거나 선택 행이 없으면 버튼을 표시하지 않거나 아무 작업도 하지 않는다.

## 검증

- 미등록 요약에서만 이동 버튼이 표시되고 올바른 자동 입력값을 전달한다.
- 설정 창이 수주 마스터 탭과 신규 행을 선택하며 자동 입력하고, 저장 성공/취소를 구분한다.
- 저장 성공 뒤 매핑 재적용, 메인 목록, 대시보드, 최종 미리보기가 갱신된다.
- 셀 선택, TSV 복사, 우클릭 복사, 상세 행 번호, 기본/버튼 정렬과 미확정 날짜 배치를 Qt offscreen 테스트로 검증한다.
