# UI 버그 및 수정 사항 목록

작성일: 2026-07-30

## 사용 방법

- 작업 전에는 각 항목의 체크박스를 비워 둔다.
- 구현과 관련 검증이 모두 끝난 항목만 `[x]`로 바꾼다.
- 실제 GUI에서 확인하지 못한 항목은 완료로 표시하지 않는다.

## 우선순위 1: 업체와 수주 마스터 등록 흐름

- [ ] 새 업체를 같은 설정창에서 추가한 뒤, 새 수주 행의 업체로 즉시 선택할 수 있게 한다.
  - 현재 문제: 업체 탭에서 아직 저장하지 않은 업체는 수주 마스터의 업체 목록에 나타나지 않는다.
  - 완료 기준: 업체를 추가하고 수주 행에서 해당 업체를 선택한 뒤 한 번의 Save로 정상 저장된다.

- [ ] 수주 행의 미완성 상태가 업체 탭의 저장까지 막지 않도록 저장 흐름을 수정한다.
  - 현재 문제: 수주 행의 업체 ID가 비어 있으면 전체 설정 Save가 실패하여 업체 등록도 저장할 수 없다.
  - 완료 기준: 업체와 수주를 같은 설정창에서 함께 추가해도 저장 순서에 따라 정상 처리된다.

- [ ] 업체 선택 오류 안내를 실제 원인에 맞게 개선한다.
  - 현재 문제: 화면에 업체명이 보여도 내부 업체 ID가 없으면 "업체를 선택하세요."만 표시된다.
  - 완료 기준: 새 업체가 아직 저장되지 않았거나 업체 선택이 필요한 이유를 사용자가 이해할 수 있는 메시지로 표시한다.

- [x] 수주 마스터의 업체 칸에 드롭다운이 명확히 표시되도록 수정한다.
  - 현재 문제: 업체 선택 UI 또는 목록이 사용자에게 보이지 않는다.
  - 완료 기준: 저장된 활성 업체가 드롭다운 목록에 표시되고, 선택한 업체가 수주에 연결된다.

## 우선순위 2: 설정 화면의 활성 상태 표시

- [x] 업체 및 수주 마스터의 `활성` 칸에 체크박스를 정상 표시한다.
  - 현재 문제: 새 행에서 체크박스가 보이지 않아 활성 여부를 확인하거나 변경할 수 없다.
  - 완료 기준: 새 행은 기본적으로 체크된 상태로 보이고, 사용자가 체크를 변경할 수 있다.

## 우선순위 3: 메인 검토표 가독성

- [ ] 오류 행의 배경색과 글자색 대비를 조정한다.
  - 현재 문제: 밝은 오류 배경 위에 다크 테마의 밝은 글자가 표시되어 행 데이터와 오류 코드가 읽기 어렵다.
  - 완료 기준: 오류 행에서 수주번호, 장비명, 수치, 검사 상태가 일반 화면에서 명확히 읽힌다.

## 우선순위 4: 사업팀 선택 표준화

- [x] 수주 마스터의 `사업팀` 칸을 드롭다운으로 변경한다.
  - 허용 목록: `MARKER`, `CSM`, `GROOVING`, `WA`, `PKG`, `PCB`, `DISPLAY`, `MACRO`, `광학영업`, `LDM`
  - 완료 기준: 새 수주 행에서는 위 목록 중 하나를 선택할 수 있다.

- [ ] 저장된 수주를 다시 열 때 저장했던 사업팀 값을 그대로 표시한다.
  - 완료 기준: 저장 후 설정창을 닫고 다시 열어도 해당 수주의 사업팀 선택값이 유지된다.

## 검증 체크리스트

- [x] 업체 드롭다운에 저장된 활성 업체가 표시되는지 확인
- [x] 활성 체크박스의 기본값과 변경 동작을 확인
- [x] 사업팀 드롭다운의 전체 허용 목록과 기존 값 복원을 확인
- [ ] 오류 행의 글자 대비를 실제 GUI에서 확인
